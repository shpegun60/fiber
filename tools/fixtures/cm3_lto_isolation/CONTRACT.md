# Current CM3 O2-LTO Common And Slot Isolation

## Fixed Scope

This additive component covers only current native CM3 p4/b16 soft-float,
O2-lto, direct evidence. It combines authenticated common-source ownership,
three dependency-isolated slim-IR compilations and a replacement link with a
bounded selected-port slot-access predicate on actual merged LTRANS code.
This contract states requirements, not a measured implementation or PASS.

The nine admitted inputs are common core/state/panic at indices 0/1/2,
selected runtime/boot/exception at 3/4/5, expectation at 6, application at 7
and native startup at 8. The first eight are slim C IR; startup is non-LTO
machine assembly. Os-lto, archives, other cohorts and reference replay are out
of scope. No runtime or frozen helper change is authorized.

## Merged-Machine Slot Boundary

The slot predicate must bind exact source bytes, actual machine/disassembly and
the corresponding map/final image, using admitted reader/transport evidence.
Preserve raw metadata and hashes. The local four-byte slot occupies its dedicated
input NOBITS section; a raw STT_SECTION target may have an empty name. Resolve
section identity, original addend, placement and final writable/non-executable
zero-fill origin instead of normalizing it into a fictitious named import.

The leaf scope is section-mediated slot access, not complete handler protocols.
It validates six complete, independently fixed common-function code-generation
protocols: load_current_context, context_configuration_is_open,
select_scheduler_candidate, publish_current_context, require_current_context
(all with the fiber_internal_runtime_ prefix), and ctxrt_v1_set_dispatcher.
Bind complete body sizes/bytes, mapping boundaries, alignment, all literal pools,
local branches and named call/tail references with original/applied addends and
mapped destinations. Retain both raw body hashes and full evidence. Across those
six bodies there are five slot loads and one store, solely in the publisher.
Do not infer general C semantics, callback behavior or callee correctness.

For each handler, bind its actual function extent and exactly one slot-address
literal use followed immediately by the pointer load: SVC uses r0, PendSV r1.
Check source/generated pairs, original/final instruction bits, complete selected
literal words, raw section targets, addends, mappings and origin/alias bounds.
The handler use census must cover both machine and final streams, not only the
expected pair or 16-bit matches. Additional loads reusing an existing slot word
still count as uses without a new REL; unsupported literal-load forms must reject
rather than evade that census. This does not forbid accessing context storage
through the loaded context pointer. Two relocation names or matching text lines
are insufficient.

Enumerate all original provider references to the dedicated slot section or
symbol and bind exactly eight classified ABS32 slot words: six common-body
references plus two handler references. Require the corresponding eight applied
references on emitted finals (zero on ordinary finals), exact slot values and no
unclassified section-mediated use. Retain the generated assembly alias/reference
census as supporting evidence, not a replacement for ELF bytes and REL metadata.
Do not require only two references across merged .text or pass whole LTRANS
assembly to the ordinary two-pair checker. Absolute constants, computed aliases
and arbitrary pointer flows are not covered by this section-mediated census.

The leaf must report CompleteHandlerBodiesValidated=False, and the runner must
retain WholeSlotAccessIsolationScope=SECTION_MEDIATED_CURRENT_CM3_O2_LTO_ONLY.
WholeSlotAccessIsolation, when true, is qualified by that scope, never a whole
program or arbitrary-alias claim. Complete native handler preservation and
canonical SVC/PendSV/first-start protocols remain independent enclosing-cell
prerequisites, recomputed through the unchanged transport/protocol predicates.
Do not relabel this narrower leaf as satisfying that separate prerequisite.

Record which machine/final pair the predicate actually checks. Comparing load
images transfers only the checked loadable-byte equality; it does not establish
fresh independent root/map/symbol provenance for an unexamined replacement
machine. Any source-trivia normalization must be narrowly bounded and retain
both original and normalized hashes, never rewrite authenticated source authority.

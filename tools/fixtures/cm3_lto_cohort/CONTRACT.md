# Native CM3 LTO Policy-Cohort Qualification

## Fixed Evidence Scope

This independent composition admits the captured native CM3 O2-lto direct-link
BASEPRI16/32 package associated with producer checkpoint `a0681ad`. The revision
label is provenance, not input authentication: the caller must supply independent
receipt/artifact SHA-256 values for the exact retained package. This contract
does not report an implementation, test, audit or measured qualification PASS.

Both policies use ARMv7-M Thumb, ordinary AAPCS, soft ABI, no FPU/MPU/TrustZone,
VTOR1 and declared priority bits 4. Only the private scheduler threshold varies.
The 32 case is a bounded policy fixture, not a new globally qualified inventory
cohort. Storage revision, private layout and reverse-v1 ABI remain unchanged.

The result combines four own-machine static final-link audits with the complete
raw evidence for eight one-object mismatch failures. It proves neither runtime
priority behavior nor full ABI, IR semantics or a new b32 canonical protocol.

Any separately retained b16 root/protocol evidence must state its own scope;
neither it nor twin equality establishes b32 root/REL/canonical validation.
The four static-audit records keep their original canonical-protocol false flags.

frozen reader/checker or default-matrix change follows from this composition.

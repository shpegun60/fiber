This is the next staged implementation, not an executed 134-command Os proof.
The existing `CONTRACT.md`, roots/bindings CLI and its source pins stay frozen.
New batch support must not change those qualified entrypoints or mutate a
frozen helper's globals to make an O2 check accept Os.

## Command Session

`batch_session.py` takes explicit authenticated helpers, buffers and that
admitted environment. The session's own source must already be enrolled before
admission closes. It reuses only the frozen neutral output/journal,
compile/dependency, plugin-NM, IR inspection and saved-LTO auxiliary mechanics.
The frozen O2 constructors, recipes, phase drivers, finish and verdict functions
are not called. Accidental calls to inherited `run_link_controls` or `finish`
are rejected; the Os orchestrator must supply their replacements explicitly.

The session retains nine actual sources/objects, eight slim providers and the
machine startup, source-copy Seed, captured environment, compiler tools and
LTO plugin. TEMP/TMP are redirected into its own fresh output; unadmitted tools
are rejected. Source mutations/additions remain explicit copies and deltas,
not edits to captured inputs. Full inherited pre-command closing and original
object checks are retained; this work introduces no weaker closing schedule.

Phase ranges are ordered, nonoverlapping and complete. Exit/expected-exit
counters must be literal integers, not booleans; timeout, journal fault,
incomplete command or wrong phase size rejects. Even completion of all four
ranges leaves Status FAIL and cell credit zero until actual Os-specific
diagnostic, declaration, isolation, stress, source/worker/final-image and
closing predicates have been composed. Infrastructure does not qualify itself.

## Parser And Isolation Work

The complete batch will collect outputs first, then inspect them in one
immutable captured-parser scope. It must not sequentially call the old phase
drivers, each of which assumes a fresh parser scope and O2 verdict contract.

`slot.py` owns source-reviewed complete Os protocols for all six common slot
consumers, including branch paths, panic calls, register allocation, returns,
alignment and pools. Frozen neutral origin/REL/mapping/handler-census helpers
may be supplied explicitly, without replacing their global PROGRAMS. Every
slot-bearing original word and projected final word must be accounted for;
foreign references, cross-owner handler loads, stores/escapes, unsupported
address formation, extra body bytes and tail padding fail closed.

Pure/synthetic tests do not establish actual Os machine behavior. Recomputing
slot predicates over authenticated original Os twins is separate static
evidence, not CPU execution or replacement for the isolated common build.
Any unimplemented phase remains pending, with no stub success or cell credit.

No runtime C/ASM, public5/port8, FreeRTOS source or hardware is modified by
this batch-support work. Full semantic ABI, C/IR/machine equivalence, arbitrary
callback safety, archive/CI/global freeze and board execution remain unproved.

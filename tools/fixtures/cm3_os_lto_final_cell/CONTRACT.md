# Current CM3 Os-LTO Static Cell Work

This additive fixture is the Os-specific home for the remaining current-source
CM3 static-cell work. Its two explicit stages are `--stage bindings` (default)
and `--stage roots`. The former proves native final-link and runtime-provider
bindings; the latter runs the frozen current Os six-root replay. Neither is a
whole-cell qualifier. Required cell credit is always literal integer zero,
including after a successful run.

## Authority And Recipes

Use fresh unoptimized `python -I -S -B` with the same ten explicit descriptors
as `cm3_current_lto_replay/witness.py`, plus the optional stage selector:
native/reference builds, receipt and
manifest hashes for both, the independent inventory and its two hashes, and a
fresh disjoint output directory. No implicit latest paths or inferred receipts
are accepted. The fixed source cut is current E9
`69A66CB09D699EA45A30B21BF4DBCD569CBE637A7770125E76EE64323D862313`.

The existing current Os constructor independently admits both complete captures,
the current 2,774-cell inventory/backlog and their ordinary source Seeds. It
reconstructs all 57 native and 37 reference capture commands, including actual
`-Os` driver/worker/link records, without executing any tools. The ordinary
O2 Seed establishes source-copy authority, not Os generated-code credit.
Neither an O2 report projection nor mutation of frozen helper globals is used.

Pinned source buffers, the new contract and runner source are enrolled before
the constructor closes. The native actual ordinary and emitted-relocation
twins each retain their own saved LTRANS, final ELF, startup, map, disassembly,
final attributes and machine attributes. Every role must belong to its
authenticated capture manifest. Seven roles per twin are physically distinct;
the startup object may legitimately be shared between twins.

## Bounded Predicates

The pure `abi.py` owns Os result schemas and orchestration. It may call the
explicitly supplied frozen mode-independent ELF/symbol/section/REL/byte
predicates and `Bindings` helper class. It must not call either helper's O2
top-level audit/inspect function and then relabel its result as Os. A predicate
that rejects actual Os lowering remains a failure until its exact alternative
is source-reviewed and tested; unsupported code is never silently ignored.

The staged proof covers the public five, forward eight, strong vectors,
runtime/private/storage identities, read-only expectation/root pointer tables,
current-slot storage geometry, four selected reverse providers and their
selected references, two cold ABI-anchor reads and three startup vector
relocations. Full containing-body bytes and map placement bind selected
references to each own actual machine and final twin. Only the emitted twin
has applied REL metadata; the ordinary twin is inspected independently and
must have the same load image. Bounded AAPCS/cold-base assumptions and unproved
caller control flow remain explicit in the pure proof.

The Os context-initialization alternative is specifically a Thumb-2 positive
PC-relative `LDR.W r8` literal followed later by `LDRB.W r3,[r8,#1]`. The earlier
cohort read at displacement zero is not accepted as the runtime ABI read.
The original section-relative ABS32 literal/addend and byte displacement must
resolve to the exact ABI anchor in both machine and final image. A closed
write-effect subset rejects possible writes to `r8` and unknown instructions
between load and read; calls require actual named original REL authority,
map-bound target and corresponding applied REL for the emitted twin. Calls
still rely on the explicitly recorded AAPCS callee-save assumption, not a
proof of each callee or control-flow dominance. This alternative does not
widen the frozen O2 matcher or skip body bytes, branches or literal pools.

One captured parser graph reads immutable buffers. Reader path resolution is
lexical only; physical identity/hash/tree closing happens outside that scope.
Unknown buffer/import access, unexpected symbol/reference/section shape,
attributes, output membership, late source drift or physical drift fail closed.
All processes and shell execution are forbidden across admission, replay,
sealing and summary printing. No target CPU executes.

## Failure And Scope

Source and binary copies are intended-byte outputs with predetermined names.
The output manifest binds the full output tree; inputs close again after the
final receipt/manifest writes. Any replay, closing, seal or flushed-stdout error
revokes positive flags and rewrites a bounded best-effort FAIL receipt/manifest.
The frozen current Os frontend remains unchanged and is not used as a CLI
entrypoint here; its earlier post-PASS stdout gap is not inherited. Both stages
keep summary printing and `flush=True` inside the same protected failure path.

The default bindings stage does not execute the separate six-root
parity/negative-control replay. Neither stage proves typed declaration
compatibility, all current-slot
writers/readers, attributes under hostile flags, five link controls, slim-IR
semantics, whole-provider semantics, source-to-machine equivalence, instruction
identity with FreeRTOS, arbitrary scheduler callbacks, archive mode, CI, CPU or
board execution, or global freeze. Those obligations remain pending in this
same staged fixture. Existing O2 component receipts provide no Os credit.

The roots stage retains the unchanged current Os authority and six-root replay,
including fresh 32 transport and two coherent canonical controls, source/binary
copies and complete closing. It adds this protected entrypoint's authenticated
source buffers but changes no predicate or frozen helper. Its result retains
the original narrow roots status/scope, separate from the bindings stage.
Neither record closes an Os required cell on its own.

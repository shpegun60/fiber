# Original CM3 Os-LTO Binding And Canonical Root Replay

## Scope

Add the original native provider-binding and native/reference six-root
canonical component to the existing one-reader Os composition. Consume the
same admitted native/reference captures, source inventory, batch and normal
handoff. Do not inherit successful verdicts from older binding, root or join
receipts, mutate frozen helpers or call an O2 top-level witness and relabel it.
Runtime C/ASM, layouts, public5/port8 and the reference pin remain unchanged.

The pure leaf surface is:

```python
inspect(core, read, native, reference, helpers, *, roles, ledgers)
require_result(proof, helpers)
```

The caller owns authenticated sources, capture admission, manifest membership,
physical identities and the immutable reader. The leaf owns exact original
role reconstruction, byte consumption, pure predicates and result joins.
Descriptors are explicit root/result/manifest authorities, never cached PASS
markers. Final validation must use the same authenticated helper versions.

## Inputs And Reader Boundary

Reconstruct native ordinary seven-role and emitted eight-role bundles, plus
the seven reference emitted/join roles: 22 logical role rows, 21 distinct
paths because native startup is shared. Native ordinary uses the seven runner
roles; native emitted adds MachineDisassembly. Reference includes Plain as
one of its seven join roles. Bind every role to its capture,
manifest hash and actual link/source record. Require distinct roles where
semantically distinct; do not manufacture disassembly or attribute evidence.

Explicitly enroll both load-image records and the shared master and policy
ledgers as reader roles. A buffer's presence in the snapshot is not permission
to read it. Read all authoritative bytes through the supplied reader, retain
their exact hashes and complete a unique-path read inventory. Including these
four additional roles gives 26 logical rows and 25 distinct paths. No filesystem,
subprocess, shell, loader fallback or late helper import belongs in the leaf.

Those 25 paths count evidence roles only. Each descriptor's receipt and
artifact manifest are independently read and joined as four additional
authority inputs, giving 29 distinct consumed byte inputs in the normal
non-aliasing case. Do not disguise authority reads as already-consumed roles.
Fix closed descriptor, role, ledger, helper and result schemas before coding.
Provide buffer-only read_bytes/read_text facades where frozen FinalImage and
decoder interfaces require them; never fall back to physical I/O.

Master is the admitted inventory's captured inputs/FREERTOS_ASM_PARITY.md,
whose hash joins both capture InputHashes records. It is not the current
working-copy documentation file. Policy is the fixed authenticated
tools/fixtures/cm3_final_join/POLICY_DIFFERENCES.md source/pin used by the
legacy Os admission. Caller-selected equivalent prose is not another authority.

Only explicit authenticated dependencies are allowed: the Os ABI predicate,
neutral link/binding helpers, native/reference root adapters, protocol views,
decoder/checker, Os join composer, neutral join/ledger rules and guard. Do not
weaken frozen predicate schemas or mutate module globals to fit Os output.

## Closed Input Schemas

The exact helper keys are:

```text
abi, link_helpers, binding_helpers, native_roots, reference_roots,
native_protocol, reference_protocol, decoder, checker, os_join, join, guard
```

Each native/reference capture descriptor has exactly Root, Result, Artifacts,
ReceiptSha256 and ManifestSha256. Root is the absolute admitted capture root;
Result and Artifacts are parsed authority comparison targets. The two digests
bind independently reread results.json and artifacts.json. Strict JSON rejects
duplicate keys and nonfinite numbers. Comparisons preserve literal types,
including booleans versus integer credits.

The roles dictionary has exactly NativeOrdinary, NativeEmitted, Reference and
LoadImages. NativeOrdinary has Machine, Final, Disassembly, LinkMap, Startup,
Attributes and MachineAttributes. NativeEmitted adds MachineDisassembly.
Reference has Machine, Final, Disassembly, LinkMap, Startup, Plain and
MachineDisassembly. LoadImages has Native and Reference. The ledgers dictionary
has exactly Master and Policy. Leaf output bindings use strings and uppercase
SHA-256 values, retain logical roles independently of path deduplication and
reject missing, foreign or cross-side roles. Receipt/manifest authority inputs
are separate from the 26 evidence rows; all 30 logical inputs occupy exactly
29 distinct paths under the one permitted shared native-startup alias.

Every inspect input leaf in roles and ledgers is also exactly a Path/Sha256
binding with string fields, not a Path object or a hashless string. The caller
may use paths internally for admission, but converts them to these bindings
before invoking the leaf. The leaf independently reconstructs each expected
path/hash from the admitted capture controls and compares the caller binding;
the caller-supplied hash is not a substitute authority.

## Binding And Canonical Proofs

Construct native ordinary and emitted FinalImage instances from each side's
own generated machine, startup provider, final executable, disassembly and
map. Run Os ABI inspect/require_result on both, including selected provider,
reverse-reference, cold-read and startup-vector obligations. Recompute the
native load-image twin comparison from bytes and join its captured record.

Construct native/reference emitted root adapters and decode each side's own
saved generated machine. Recompute all six complete transport roots through
the unchanged views/checker and the explicit Os check_join composition. Do
not consume O2-scoped check_native/check_reference reports as Os evidence.
Validate both captured ledgers and preserve declared difference rationales.
Pass the master ledger to Os check_join and separately validate the policy
ledger through require_ledger(policy_text, proof['ProtocolProof']).
Recompute reference load twins independently as well.

Keep original transport records unchanged, including their false canonical
fields. Canonical evidence belongs to the composed protocol result. Do not
replace body evidence with symbol-name presence, raw text equality, selected
instruction snippets or a prior result flag.

The enclosing composer must join native originals, maps, startup, receipts,
source fingerprint and cohort to the original census, isolation and port
authorities. Share one immutable reader for all components. Re-run detailed
leaf validation and cross-component joins at the final result boundary.
